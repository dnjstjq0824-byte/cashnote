# 카드·배달 정산 및 은행 입금 대사 E2E 테스트 명세서 (Scenario C, D, F)

**문서 ID**: TEST-RECON-002  

---

## 1. Scenario C & D: 카드 승인 → 매입 → 공휴일 이연 → 취소 상계 → 은행 입금 대사 → 미입금 진단 E2E

### Given (사전 조건)
- 매장 `store_A` (`VERIFIED_OWNER`, 일반과세자 음식점, 신한은행 정산계좌 `*1234` 등록).
- 신한카드 영세가맹점 우대수수료율 `0.5%` 설정, 정산 주기 `D+2 영업일`.

### When (실행 시퀀스)
1. **10월 23일(목)**: 신한카드 승인 10건 합계 `1,100,000원` (공급가 `1,000,000원`, 부가세 `100,000원`) 발생 및 전표 매입 확정 (`fee_amount = 5,500원`, `expected_net_deposit = 1,094,500원`).
2. **10월 24일(금)**: 전일 결제건 중 1건 `110,000원` 매입 후 취소(`POST_CAPTURE_FULL_CANCEL`) 발생 → 차기 지급 예정액에서 `-109,450원` 상계 예약.
3. **10월 27일(월, D+2 영업일)**:
   - Case 1: 신한은행 통장 내역이 아직 업로드/동기화되지 않은 상태에서 오전 09:00 진단 실행 → `SYNC_DELAY_PENDING` (미입금 사고로 단정하지 않음).
   - Case 2: 오전 10:00 신한은행 통장 내역(`입금자: 신한카드, 입금액: 985,050원`) 업로드 → 자동 대사 실행.

### Then (기대 검증 결과)
- `1,094,500원(원 예정액) - 109,450원(매입후취소 상계) = 985,050원(실제 통장 입금액)`이 오차 `0원`, 신뢰도 `100.00%`로 `RECONCILED_MATCHED` 처리된다.
- 복식부기 원장에 `[차] 보통예금 985,050 / [대] 카드미수금 985,050` 분개가 생성되고 카드미수금 잔액이 `0원`이 된다.
- 만약 실제 통장에 `900,000원`만 입금되었다면 차액 `85,050원`이 `VARIANCE_DETECTED`로 분류되고 사장님께 알림이 발송되며, 사장님이 이의제기/정정 후 재대사하면 `RESOLVED`로 전환된다.
