# Flutter Android/iOS 모바일 앱 E2E 및 오프라인 동기화 테스트 명세서

**문서 ID**: TEST-MOBILE-004  

---

## 1. 모바일 핵심 E2E 테스트 시나리오

1. **M-E2E-01 (생체인증 및 앱 스위처 프라이버시 보호)**:
   - 앱 실행 → FaceID/지문 인증 통과 → 홈 대시보드 오늘 입금 예정액 렌더링(< 300ms) 확인 → OS 홈 버튼으로 백그라운드 전환 시 즉시 금액 블러 오버레이 작동 확인.
2. **M-E2E-02 (현장 영수증 카메라 촬영 및 OCR 기장)**:
   - 하단 중앙 `+` 버튼 탭 → `[영수증 촬영]` → 식자재 영수증 촬영 및 자동 원근 보정 → S3 업로드 및 OCR 추출(공급가 40,000원 + 부가세 4,000원) → 사장님 확인 탭 → 비용 장부(`expenses`) 및 부가세 대급금 원장 즉시 반영 확인.
3. **M-E2E-03 (지하 매장 오프라인 입력 및 온라인 복구 동기화)**:
   - 기기 네트워크를 오프라인(Airplane Mode)으로 전환 → 상단 주황색 `[오프라인 모드]` 배너 노출 확인 → 현금매출 2건 및 간이영수증 지출 1건 입력 → 로컬 `SQLCipher` 큐에 암호화 저장 확인 → 네트워크 온라인 복구 → 3초 이내에 `POST /v1/stores/{id}/mobile/offline-sync` 자동 호출 및 중복 없이 서버 원장 반영 확인.
