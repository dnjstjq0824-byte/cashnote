# 불변 복식부기 원장 및 손익(P&L) 산출 엔진 명세서

**문서 ID**: FIN-LEDGER-004

## 1. 관리회계 손익계산서(P&L) 표준 산출 공식 (제9조 반영)

소상공인 업종별 손익계산서는 다음 계층 구조로 계산되며 모든 항목의 산식이 UI 툴팁과 내보내기 엑셀 수식에 그대로 노출된다:

1. **총매출액 (`Gross Sales`)** $= \sum (	ext{카드승인매출} + 	ext{현금영수증/현금매출} + 	ext{배달앱주문매출} + 	ext{매출세금계산서})$ (취소분 차감 후, 부가세 포함가 기준 병기)
2. **순매출액 (`Net Sales / Supply Value`)** $= 	ext{총매출액} - 	ext{매출부가가치세(예수금)} - 	ext{매출에누리/할인쿠폰(사장님부담분)}$
3. **매출원가 (`COGS`)** $= 	ext{식자재/원재료 매입액} + 	ext{상품 매입액} + 	ext{기초재고} - 	ext{기말재고}$
4. **매출총이익 (`Gross Profit`)** $= 	ext{순매출액} - 	ext{매출원가}$ (매출총이익률 $= 	ext{매출총이익} / 	ext{순매출액} 	imes 100\%$)
5. **변동 수수료 (`Platform & Payment Fees`)** $= 	ext{카드결제수수료} + 	ext{PG수수료} + 	ext{배달앱 중개수수료} + 	ext{배달대행료(사장님부담분)}$
6. **공헌이익 (`Contribution Margin`)** $= 	ext{매출총이익} - 	ext{변동 수수료} - 	ext{포장재/소모품비}$
7. **고정 판관비 (`Fixed Operating Expenses`)** $= 	ext{인건비(정직원+알바+4대보험)} + 	ext{임차료/관리비} + 	ext{수도광열/통신공과금} + 	ext{광고선전비} + 	ext{기타경비}$
8. **추정 영업이익 (`Estimated Operating Profit`)** $= 	ext{공헌이익} - 	ext{고정 판관비}$
9. **순현금흐름 (`Net Cash Flow`)** $= 	ext{기간 내 실제 계좌 총입금액} - 	ext{기간 내 실제 계좌 총출금액}$ (발생주의 영업이익과 현금주의 통장 증감액의 차이를 브릿지 표로 설명)
