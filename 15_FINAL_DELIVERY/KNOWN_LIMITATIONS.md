# 외부 계약·인허가 필요 사항(BLOCKED) 및 설계/라이브 검증 경계 명세서 (Known Limitations & Regulatory Blockers)

**문서 ID**: FINAL-LIM-003  
**관련 조항**: 제3조, 제28조, 제29조, 제30조 제15항, 제31조

---

## 1. 제29조 & 제31조 원칙에 따른 투명한 구분 보고

본 패키지는 후속 개발 에이전트가 전체 플랫폼을 즉시 구현·테스트할 수 있도록 설계된 **완전한 마스터 블루프린트 및 실행 패키지**이다. 제31조("실제 API가 없는데 가짜 API 작성 금지", "Mock 테스트만으로 상용 완료 선언 금지")에 의거하여, **즉시 상용 구동 가능한 영역**과 **외부 기관 계약·행정 인허가가 선행되어야만 라이브 전환 가능한 영역(`BLOCKED`)**을 다음과 같이 정직하고 명확하게 구분한다:

| 구분 코드 | 대상 기능 / 외부 API | 현재 상태 | 사유 및 선행 필요 조치 | 현재 상태에서 즉시 동작하는 대체 경로 (Level 1~2) |
|---|---|---|---|---|
| **LIM-01** | **여신금융협회 매통조 Open API 직접 연동** (`API-KR-002`) | `CONTRACT_REQUIRED` (라이브 자동수집 `BLOCKED`) | 여신금융협회와의 가맹점 매출거래정보 오픈API 이용 협약 또는 공인 데이터 중계사 계약 및 보안심사 통과 필요 | **즉시 사용 가능**: 여신금융협회 및 9대 카드사 웹사이트에서 내려받은 승인·매입·입금내역 엑셀/CSV 업로드 파서(`LEVEL_2_FILE`) |
| **LIM-02** | **금융결제원 오픈뱅킹 실시간 계좌 조회 및 1원 인증** (`API-KR-004`) | `APPROVAL_REQUIRED` (라이브 API `BLOCKED`) | 금융결제원 오픈뱅킹 이용적합성 승인(약관 제14조) 및 분담금/보안점검 완료(또는 펌뱅킹 중계사 계약) 필요 | **즉시 사용 가능**: 시중 18개 은행 통장 거래내역 엑셀/CSV 업로드 파서(`LEVEL_2_FILE`) 및 사업자등록증명원 서류 소유권 검증 |
| **LIM-03** | **배달 플랫폼(배민·쿠팡이츠·요기요) 실시간 정산 연동** (`API-KR-010`) | `PARTNER_ONLY` (실시간 API `BLOCKED`) | 배달 3사는 일반 서드파티에 공개 정산 Open API를 개방하지 않으며, 제11조에 따라 비밀번호 무단 수집 스크래핑을 전면 배제함 | **즉시 사용 가능**: 배민셀프서비스·쿠팡이츠스토어·요기요 사장님사이트에서 제공하는 공식 정산 명세서 엑셀/CSV 업로드 자동 파서(`LEVEL_2_FILE`) |
| **LIM-04** | **전자세금계산서 직접 국세청 전송 및 홈택스 자동 수집** (`API-KR-005~007`) | `COMMERCIAL_PROVIDER` / `LICENSE_REQUIRED` | 직접 전송은 국세청 표준인증 시스템사업자 등록 필요. 초기에는 팝빌/바로빌 등 공인 ASP와 B2B 이용계약 체결 필요 | **즉시 사용 가능**: 홈택스 전자세금계산서·현금영수증 엑셀 업로드(`LEVEL_2_FILE`) 및 종이세금계산서/영수증 OCR 스캔 등록 |
| **LIM-05** | **맞춤형 대출 금리·한도 비교 중개 및 개인사업자 신용점수(CB)** | `REGULATORY_BLOCKED` | 금융소비자보호법상 온라인 대출성 금융상품판매대리·중개업 등록 및 신용정보법상 개인사업자 CB 허가 취득 전까지 법적으로 제공 불가 | **즉시 사용 가능**: 비규제 영역인 중소벤처기업부/소상공인시장진흥공단 공식 정책자금·지원사업 맞춤 공고 추천(`PUBLIC_API`) |
| **LIM-06** | **네이버 플레이스 / 카카오맵 리뷰 직접 답글 API** (`API-KR-011`) | `PARTNER_ONLY` (직접 게시 `BLOCKED`) | Google Business Profile과 달리 공개 서드파티 리뷰 답글 등록 API 미제공 | **즉시 사용 가능**: AI 맞춤 답글 초안 생성 + 원클릭 클립보드 복사 + 해당 사장님 관리앱 실행 딥링크 워크플로우 |
