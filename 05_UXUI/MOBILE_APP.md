# Flutter Android/iOS 모바일 앱 UX/UI 및 네이티브 기능 설계

**문서 ID**: UX-MOBILE-006  

---

## 1. 모바일 바텀 내비게이션 5탭 구조

1. **홈 (`Tab 1`)**: 오늘 입금 예정액, 어제 매출, 미입금/리뷰 알림 배지, 매장 전환 칩.
2. **장부·정산 (`Tab 2`)**: 매출 캘린더, 카드매출 5단계 워터폴, 배달 정산, 미입금 진단.
3. **+ 기록/촬영 (`Tab 3 - 중앙 플로팅 액션 버튼`)**:
   - `[영수증/세금계산서 카메라 촬영 (OCR)]`
   - `[현금 매출 5초 수기 입력]`
   - `[비용/경비 수기 입력]`
   - `[모바일에 저장된 정산 엑셀 파일 업로드]`
4. **리뷰·고객 (`Tab 4`)**: 신규 리뷰 인박스, AI 답글 생성 및 원클릭 복사/등록, 단골 현황.
5. **전체 메뉴 (`Tab 5`)**: 세금 예상, AI 분석, 지원정책, 사장님 커뮤니티, B2B 마켓, 멤버십, 연동/보안 설정.

## 2. 모바일 특화 UX 요구사항

- **오프라인 입력 큐 표시**: 지하 매장 등에서 네트워크가 끊기면 상단에 주황색 `[오프라인 모드 — 입력하신 매출/영수증은 인터넷 연결 시 자동 저장됩니다 (대기 2건)]` 바가 나타난다.
- **앱 스위처 프라이버시 블러**: 앱이 백그라운드로 내려가는 즉시 OS 최근 앱 목록 화면에 매출 금액이 노출되지 않도록 로고 블러 화면으로 덮는다.
