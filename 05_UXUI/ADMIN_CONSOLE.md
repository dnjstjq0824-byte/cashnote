## 1. 관리자 콘솔 핵심 거버넌스 UI 원칙

1. **가맹점 금융 데이터 기본 마스킹 및 Break-Glass 열람**:
   - 일반 관리자 목록(`SCR-AD-04`)에서는 개별 매장의 매출액과 계좌번호가 마스킹되어 표시된다.
   - 가맹점주가 CS 문의를 통해 발급한 **일회용 6자리 열람 승인 코드**와 **CS 티켓 번호(`support_ticket_id`)**를 `SCR-AD-15`에 입력해야만 30분간 읽기 전용 미러 뷰가 열리며, 상단에 붉은색 `[감사 기록 중: CS-2026-9981 열람 세션 (남은 시간 28:14)]` 배너가 고정된다.
2. **4-Eyes (2인 승인) 제어 모달 (`SCR-AD-05`, `SCR-AD-14`)**:
   - 외부 커넥터 라이브 전환(`is_live_enabled`), 규제 게이트 변경, 고액 환불 처리는 1차 관리자가 기안(`PENDING_SECOND_APPROVAL`)하면 다른 관리자 계정이 MFA 서명으로 2차 승인을 완료해야 실행된다.
