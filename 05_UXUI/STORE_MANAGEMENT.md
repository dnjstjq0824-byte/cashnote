# 사업장 관리·소유권 인증·권한·데이터 연동 UX/UI 상세 설계

**문서 ID**: UX-STORE-005

## 1. 사업자 실체 확인 vs 소유권 검증 분리 UX (`SCR-SM-01`)

제6조 원칙에 따라 사업자번호만 입력했다고 해서 매장 대시보드의 금융 연동을 열어주지 않는다:
1. **Step 1 (국세청 실체·상태 확인)**: 10자리 사업자등록번호, 대표자성명, 개업일자 입력 → 국세청 진위확인/상태조회 API 호출 → `[계속사업자 / 부가가치세 일반과세자 확인됨]` 배지 표시. (이 시점의 권한은 `NTS_VALIDATED`이며 외부 금융 데이터 연동 불가)
2. **Step 2 (대표자 본인 및 소유권 증명)**:
   - **개인사업자 단독대표**: 본인명의 휴대전화 인증 성명 == 국세청 대표자 성명 일치 확인 + 사업자 명의 은행 계좌로 발송된 1원 입금자명(`BN인증4829`) 4자리 코드 입력 시 즉시 `VERIFIED_OWNER` 승격.
   - **법인사업자 또는 공동대표/대리인**: 사업자등록증명원 + 법인등기부등본/위임장 스캔 업로드 → 관리자 심사 큐(`SCR-AD-03`) 승인 후 `VERIFIED_OWNER` 승격.

## 2. Level 2 정산파일 Drag & Drop 업로드 마법사 (`SCR-SM-06`, `SCR-SM-07`)

- 여신금융협회, 신한/국민/삼성 등 카드사, 시중은행, 홈택스, 배달의민족, 쿠팡이츠, 요기요에서 내려받은 원본 엑셀(`.xlsx`, `.xls`) 또는 `.csv` 파일을 드래그 앤 드롭하면 자동으로 기관과 파일 양식을 감지하고, 중복 파일 여부를 SHA-256으로 0.1초 만에 검사한 뒤 파싱 결과를 미리보기로 보여준다.
