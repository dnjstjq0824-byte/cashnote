# 매출·정산·미입금 진단 UX/UI 상세 설계 (Sales & Settlement UX)

**문서 ID**: UX-SALES-003  
**대상 화면**: `SCR-UD-02`, `SCR-UD-03`, `SCR-UD-04`, `SCR-UD-06`, `SCR-UD-07`, `SCR-UD-08`, `SCR-UD-13`

## 1. 5-Stage 카드 및 배달 정산 브릿지 워터폴(Bridge Waterfall) UI

사장님이 "왜 어제 100만 원어치 팔았는데 통장에는 84만 원만 들어오나요?"라는 의문을 1초 만에 해소할 수 있도록 모든 정산 상세 화면 상단에 브릿지 바를 배치한다:

```
[1. 고객 결제 승인총액]   1,100,000원 (공급가 1,000,000원 + 부가세 100,000원)
   ├─ (-) 승인 후/매입 후 취소 상계 : -110,000원 (10/26 취소분 차감)
[2. 전표 매입 확정액]       990,000원
   ├─ (-) 카드/플랫폼 수수료 및 배달비 : -14,850원 (적용 수수료율 1.5%)
   ├─ (-) 지급 보류 / 리스크 홀드      :      0원
[3. 순정산 입금 예정액]     975,150원 (예정일: 2026-10-29 화요일, 신한은행 *1234)
   ├─ (↔) 실제 통장 입금 대사 결과     :  975,150원 입금 확인 완료 ✓ (신뢰도 100%)
[4. 미입금/차액 잔액]             0원
```

## 2. 미지급·누락 매출 진단(`SCR-UD-08`) 오탐 방지 UI 설계

- **상태 배지 3단계 분리**:
  1. `데이터 갱신 대기 (SYNC_DELAY_PENDING)`: 회색/파란색 안내 카드 — *"은행 계좌 또는 카드사 매입 내역이 아직 오늘자 최신 상태로 동기화되지 않았습니다. 미입금 사고가 아닐 수 있으니 [계좌 새로고침] 또는 [통장 엑셀 업로드]를 진행해 주세요."*
  2. `입금 지연 후보 (DELAYED_CANDIDATE)`: 앰버 경고 카드 — *"정산 예정일(10/27)이 지났으나 연결된 계좌에서 일치하는 입금액을 찾지 못했습니다. 타 계좌 입금 여부나 매입후취소 상계를 확인해 주세요."*
  3. `지급 보류 / 확정 미수금 (CONFIRMED_UNPAID)`: 크림슨 경보 카드 — *"카드사/플랫폼 정산 명세에서 지급보류(Hold) 또는 정산 누락이 확인되었습니다. [카드사 소명 자료 PDF 내보내기]"*
