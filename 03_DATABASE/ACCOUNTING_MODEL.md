# 소상공인 복식부기 원장 및 정산 회계 모델 (Accounting Model)

**문서 ID**: DB-ACCT-003

## 1. 5대 금액 엄격 분리 원칙 (제7조 구현)

BN Merchant OS는 하나의 거래에서 발생하는 다섯 가지 금액을 절대 단일 컬럼으로 합치지 않는다:

1. **승인금액 (`authorized_amount`)**: 고객이 카드를 긁거나 배달앱에서 결제한 총액 (`공급가액 + 부가가치세 + 봉사료`).
2. **회계상 매출액 (`supply_amount` / `net_sales_amount`)**: 부가가치세(일반과세자 10% 예수금 부채)와 취소/할인을 제외한 실제 수익 인식 금액.
3. **매입확정금액 (`captured_amount`)**: 카드사/PG사에 전표 매입이 완료된 금액 (승인 후 매입 전 취소 건 제외).
4. **순정산예정금액 (`net_settlement_scheduled_amount`)**: 매입확정금액에서 카드/PG/배달 중개수수료, 배달비 분담금, 광고비, 매입후취소 상계액을 차감하여 지급 예정일(`scheduled_payout_date`)에 입금되기로 약속된 금액.
5. **실제 은행 입금액 (`actual_bank_deposit_amount`)**: 실제 사업자 은행 계좌(`bank_deposits`)에 찍힌 입금액.

## 2. 핵심 거래 유형별 표준 복식부기 분개 규칙 (Journal Entry Rules)

### 사례 A: 일반과세자 식당 — 신한카드 110,000원 결제 후 D+2 영업일 수수료(0.8% = 880원) 차감 입금
- **Step 1 (매입 확정 시점, `journal_entries` #1)**:
  - `[차변] 108 카드미수금 (신한카드) : 109,120원`
  - `[차변] 831 지급수수료-카드 : 880원`
  - `[대변] 401 카드매출 : 100,000원`
  - `[대변] 255 부가세예수금 : 10,000원`
- **Step 2 (D+2 실제 은행 입금 대사 완료 시점, `journal_entries` #2)**:
  - `[차변] 102 보통예금 (신한은행) : 109,120원`
  - `[대변] 108 카드미수금 (신한카드) : 109,120원`

### 사례 B: 배달의민족 주문 22,000원 (음식값 20,000 + 부가세 2,000), 중개·결제수수료 2,156원, 사장님 부담 배달비 3,300원 차감 후 16,544원 정산 입금
- **Step 1 (배달 주문 정산 명세 확정 시점)**:
  - `[차변] 109 배달플랫폼미수금 (배민) : 16,544원`
  - `[차변] 832 지급수수료-배달중개/결제 : 1,960원`
  - `[차변] 834 배달대행료(사장님부담) : 3,000원`
  - `[차변] 135 부가세대급금 (수수료/배달비 매입세액) : 496원`
  - `[대변] 403 배달매출 : 20,000원`
  - `[대변] 255 부가세예수금 : 2,000원`
- **Step 2 (은행 계좌 16,544원 입금 대사 완료 시점)**:
  - `[차변] 102 보통예금 : 16,544원`
  - `[대변] 109 배달플랫폼미수금 (배민) : 16,544원`
